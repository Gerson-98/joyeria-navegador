# Joyería — demo de ventas y caja

App web instalable (PWA) para mostrar a joyerías. Funciona sin internet y guarda
los datos en el propio dispositivo (IndexedDB).

## Acceso rápido a la demo
- Usuario: **demo**
- Contraseña: **demo**

No hay códigos de vendedor: quien entra con sesión queda como responsable de las ventas y la caja.

## Qué trae
- 12 joyas de ejemplo con imagen (anillos, aretes, cadenas, dijes, pulseras, relojes, juegos).
- 14 días de ventas de ejemplo para ver reportes y ganancia.
- Venta con carrito, pago en efectivo/tarjeta/depósito, recibo, apertura y cierre de caja, gastos.

Las imágenes son ilustraciones propias; precios y costos son inventados.

## Desarrollo
```bash
npx --yes serve -l 3021
```
